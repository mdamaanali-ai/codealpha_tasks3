# 🚗 Car Price Prediction using Machine Learning

## 📌 Project Overview

Car Price Prediction is a Machine Learning project that predicts the price of a car based on different features like:

- Brand
- Year
- Horsepower
- Mileage
- Engine Size

The project uses Machine Learning regression techniques and provides an interactive web application using Streamlit.

---

# 🎯 Objective

The main objective of this project is to build a model that can estimate car prices automatically based on vehicle specifications.

---

## Programming Language

- Matplotlib
- Streamlit

## Machine Learning Algorithm
- Linear Regression
